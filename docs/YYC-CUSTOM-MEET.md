# Legacy: YYC Custom Meet (WebRTC beta)

**This implementation is no longer the active meeting provider.** YYC has switched back to Jitsi Meet, with meeting creation, scheduling, and invite validation remaining in the YYC/Supabase layer.

For the current call flow, see [YYC Jitsi Meet](./YYC-JITSI-MEET.md).

This file is retained as a historical note so the removed custom WebRTC beta is not mistaken for the production call path.
