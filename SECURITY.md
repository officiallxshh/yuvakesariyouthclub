# Security Policy

Yuvakesari Youth Club (YYC) welcomes responsible reports about security issues affecting this website, its public repository, or its connected Supabase-backed features.

## Supported versions

| Component | Support |
| --- | --- |
| Current code on the `main` branch | Security fixes are considered |
| Current public website deployment | Security reports are accepted |
| Older commits or unofficial copies | Not guaranteed to receive fixes |

YYC is a community project, so response and remediation times may vary. The current version is the best starting point for a report.

## Report a vulnerability privately

**Please do not publish exploitable details, access tokens, member data, or screenshots containing personal information in a public issue or social-media post.**

1. Use GitHub's private vulnerability-reporting option for this repository if it is available.
2. If that option is unavailable, contact YYC administration through the official [Contact YYC page](https://www.yuvakesariyouthclub.in/contact.html) or official Instagram account and ask for a private security-reporting channel. Do not post sensitive proof-of-concept details in a public WhatsApp group.
3. Include the affected page or feature, the steps needed to reproduce the issue, the potential impact, and a safe way to contact you. Remove personal data and secrets from screenshots and logs.

YYC aims to acknowledge a clear report within seven days and provide an initial assessment or status update within fourteen days. These are targets rather than a guarantee; complex issues may take longer.

Please allow reasonable time for investigation and a fix before disclosing technical details publicly. Reports made in good faith should avoid accessing, changing, downloading, or deleting other people's data, and should stop once the issue is demonstrated.

## What not to send

Never include passwords, session tokens, API secrets, full member records, or private photographs in an issue or message. The website's public publishable Supabase key is intended for browser use, but administrative tokens and service-role credentials are not public and must never be shared.
